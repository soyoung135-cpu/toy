# LLM 제공자와 모델 선택

## Decisions

- LLM 호출은 OpenRouter API 하나로 한다. 키 하나로 여러 회사 모델을 쓰고, 모델은 ID만 바꿔 교체한다.
- 페르소나와 실시간으로 주고받는 대화 응답은 `openai/gpt-6-luna`를 쓴다.
- 대화가 끝난 뒤 한 번 만드는 교정(단어·문장 교정, 이후 발음 피드백 포함)은 `openai/gpt-6-luna-pro`를 쓴다. 교정 품질 기준(해당 spec의 교정 정확도 eval)을 통과하지 못하면 `anthropic/claude-sonnet-5.5`로 올린다.
- 모델은 버전이 고정된 ID로 지정한다. 항상 최신으로 연결되는 별칭(`~openai/gpt-luna-latest` 등)은 쓰지 않는다.

## Boundaries

- 두 용도 밖의 새 LLM 호출(예: 페르소나 생성, 막힐 때 힌트)은 이 결정이 정하지 않는다. 그 작업에서 응답 속도와 품질 요구를 보고 따로 정하되, 제공자는 OpenRouter를 쓴다.
- 모델 이름이 바뀌어도 "대화는 빠르고 싼 모델, 대화 후 교정은 더 깊이 생각하는 모델"이라는 나눔은 유지한다.

## Why

개인용이라 상용 앱 구독료 같은 비용 부담이 없어야 한다(`PRODUCT.md`). 2026-11-19 OpenRouter 모델 API 기준 가격(1M 토큰당 입력/출력)은 GPT-6 Luna와 Luna Pro가 $0.10/$0.50, Claude Haiku 5.5도 $0.10/$0.50, Claude Sonnet 5.5는 $2/$10이다. 출퇴근 하루 2회, 회당 20턴과 교정 1회로 추정하면 대화 약 $0.4, 교정 약 $0.5(Luna Pro는 생각 토큰을 많이 써서 출력 토큰을 10배 안팎으로 가정)로 월 $1 안팎이다. 교정을 Sonnet 5.5로 하면 교정만 월 약 $1.5가 된다.

OpenRouter는 토큰 가격에 웃돈이 없고 크레딧 충전 때 5.5%(최소 $0.80) 수수료만 붙는다(공식 FAQ). 이 수수료보다 모델을 ID 하나로 바꿔 볼 수 있는 이점이 크다. 교정 모델을 싼 쪽으로 시작하고 eval 결과에 따라 올리는 방식이 이 이점에 기댄다.

음성 대화는 응답이 늦으면 흐름이 끊기므로 실시간 대화에는 빠르고 싼 Luna가 맞다. 교정은 틀리면 학습을 해치므로 같은 모델을 깊이 생각하는 모드로 돌린 Luna Pro를 쓰고, 품질 기준으로 지킨다.

별칭은 새 모델이 나올 때 알림 없이 바뀌어 eval을 통과했던 동작이 모르는 사이 달라질 수 있고, Luna Pro용 별칭은 없어 두 모델의 세대가 어긋날 수 있다. 그래서 고정 ID를 쓰고, 새 모델은 eval을 다시 돌린 뒤 직접 올린다(사용자 확정).

## Reconsider when

- 실제 사용에서 Luna의 대화 품질(페르소나 유지, 쉬운 말투)이 연습에 방해될 만큼 떨어질 때
- 새 Luna 세대가 나올 때(eval을 다시 돌려 통과하면 ID를 올린다)
- 월 사용 비용이 위 추정의 두 배를 넘을 때

## Still-rejected alternatives

- Anthropic API 직접 호출(대화 Haiku 5.5, 교정 Sonnet 5.5) — 처음 정했던 조합이다. 수수료는 없지만 다른 회사 모델로 바꿔 보기 어렵고 교정 비용이 더 든다; OpenRouter 장애나 정책 변경이 잦아지면 다시 본다.
- 항상 최신 별칭 사용 — 위 Why의 이유로 쓰지 않는다.
